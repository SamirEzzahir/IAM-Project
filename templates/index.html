Bulk Mutation CMD&Login

Import Excel avec Commande GPON, Login, ODF/ZR, PCO et brin.

Mutation réelle. Pour chaque ligne, l’application essaie d’abord la Commande avec le mode NNETO. Si WimTech retourne frm:ot_4, elle recommence avec le Login. Le brin demandé est muté même s’il est FIBRE-Active ; son Login actuel est enregistré avant le clic sur Muter vers (+).
Colonnes utilisées Commande GPON · Login · ODF · PCO · brin Ex. OFOF-ZO + 2711 → ODF OFOF · ZR OFOF-ZO · PCO OFOF-ZO-2711
